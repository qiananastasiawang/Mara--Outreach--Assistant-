# MARA Outreach Assistant Web App V2.0

Mobile-first static web app for public outreach-event research and workflow tracking.

## Deploy
This app is static: deploy the repository root to GitHub Pages, Cloudflare Pages, Netlify, or Vercel. No build command is required; `index.html` is the entry point.

## Privacy boundary
Public event and organizer information only. Do not add HEAP lists, client names, phone numbers, income documents, application records, or other client PII.

## Geographic rule
MARA ZIP eligibility is the geographic source of truth. City names are not exclusion rules. Until the authoritative ZIP master is loaded, use the official Maravilla ZIP checker and record In MARA / Outside manually.
